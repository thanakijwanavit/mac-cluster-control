# Obsidian vault

The **repository root** is the vault (same pattern as opening a folder, not a nested `vault/` directory).

| | |
|---|---|
| Open | Obsidian → Open folder as vault → `~/stacks/mac-cluster-control` |
| Wikilinks | shortest path, Obsidian `[[wikilink]]` style (not markdown links) |
| Templates | `templates/` via core Templates plugin |
| Attachments | `attachments/` |
| Gitignored | `.obsidian/workspace.json`, `private/**` |

Vanilla core plugins only — graph, backlinks, properties, templates. No community plugins until we need one.
